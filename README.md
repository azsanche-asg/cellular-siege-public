# Cellular Siege

A portrait strategy game prototype about growing a cellular defense and containing corruption.

[Cellular Siege at Burrito’s Labs](https://burritoslabs.com/catalogue/cellular-siege/)

## Technology

Swift, SwiftUI and SpriteKit.

## Architecture

A deterministic Swift simulation updates growth, threats and corruption. A distinct pixel renderer presents the board and translates touches into player actions.

## Product behavior

The public preview shows the playable defense loop. Campaign and release features are subject to development.
